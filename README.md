# data-cleaning-project
Cleaning and preparation of a raw business dataset using Microsoft Excel, including data quality checks, corrections, and validation.
Data Cleaning Project

## Project Overview

This project focuses on cleaning and preparing a raw business dataset for further analysis.

The objective was to identify data quality issues in the original dataset, apply appropriate corrections, and produce a clean and analysis-ready dataset.

This project focuses specifically on data preparation and quality, rather than business analysis or dashboard development.

## Dataset

The dataset contains business transaction records with information relating to sales, revenue, products, customers, dates, locations, and other transaction-related fields.

The original dataset was used as the starting point for the cleaning process.

## Data Cleaning Process

The dataset was reviewed for common data quality problems, including:

- Missing values
- Inconsistent text values
- Incorrect or inconsistent formatting
- Invalid data entries
- Duplicate or inconsistent records
- Inconsistent categorical values
- Incorrect data types
- Other anomalies identified during the review

The identified issues were corrected where appropriate, while values that required further review were treated carefully rather than changed without sufficient evidence.

## Workbook Structure

The Excel workbook contains the following worksheets:

1. Raw Data

Contains the original dataset before any cleaning or modifications.

2. Data Quality Report

Contains identified data quality issues and observations found during the cleaning process.

The report documents the fields affected, the type of issue identified, and the action required or taken.

3. Clean Data

Contains the final cleaned and validated dataset produced after the data preparation process.

This dataset is structured to be suitable for subsequent analysis.

## Project Purpose

The purpose of this project is to demonstrate practical data-cleaning skills and the ability to transform a raw, inconsistent dataset into a reliable dataset suitable for analysis.

The project focuses on data quality rather than analytical conclusions, allowing the cleaning and preparation process to be evaluated independently.
